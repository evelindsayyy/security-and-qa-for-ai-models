# Garak Testing

This directory is for Garak safety and red-team experiments against Duke AI Gateway models.

Use this space for Garak configs, notes, small scripts, and reproducible command examples. Generated reports and logs should go in `output/`, which is ignored by Git except for its README.

Suggested layout:

```text
safety/garak_testing/
  README.md
  output/
    README.md
```

Do not commit API keys, `.env` files, or large generated Garak outputs. Keep checked-in files small enough for teammates to inspect and rerun.
