How to read this

  • Dimension columns come from each run's rubric; the rubric YAML defines each scale (most are 1–5, tone is 1–3). Higher is better. A run shows "—" for dimensions its rubric doesn't define.
  • Overall = rubric-weighted normalized score on the 0–5 display scale.
  • Rows are sorted best-first by overall mean. The top row also carries a best badge.
  • An ⚠ N/n empty badge means the candidate returned empty text for N of n questions — usually a reasoning model that spent its max_tokens budget on hidden reasoning. The score for those rows is not a real model comparison.
