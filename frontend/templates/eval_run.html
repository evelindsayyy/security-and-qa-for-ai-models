How to read this

Score columns
From each run's rubric (usually 1–5; tone 1–3). Higher is better; "—" means not graded.
Overall
Weighted rubric score on 0–5 — headline per run. Click a row for per-question detail.
q / $
Quality per dollar (overall ÷ cost/response). Higher is more efficient; N/A for $0 self-hosted models.
Value
Weighted tradeoff w_Q·quality − w_C·cost − w_L·latency (weights shown above the table); compares models within a suite, not an absolute score.
⚠ empty
Candidate returned no text (often token budget) — re-run with higher max-tokens before comparing.

Compare
Matrix of overall scores (suite × model). Best run per suite shown when multiple judges exist.
