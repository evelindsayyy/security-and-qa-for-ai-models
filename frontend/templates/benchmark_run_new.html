How to fill in the model

Gateway — models already on the Duke LLM gateway. No extra setup.

  1. Pick a model from the dropdown (same id as the catalog).
  2. Choose a benchmark and start the run.

Example: GPT 4.1 Mini

Hosted — Hugging Face serves the model via Inference Providers. No GPU or DCC needed.

  1. Find a model with the Inference Available spark on HF models.
  2. On the model page, open Inference Providers and confirm Chat Completion is listed.
  3. If the model is gated, accept the license on that page first.
  4. Create a fine-grained token with Make calls to Inference Providers (add gated-repo read if needed).
  5. At Inference Providers settings, set routing to Automatic or enable the provider shown on the model page.
  6. Model field: paste the repo id — org/model. If you get “not supported by any provider”, pin one: org/model:provider (provider name is on the model page).
  7. Token field: paste hf_… (used once for this run, not stored).

Examples:

  • meta-llama/Llama-3.1-8B-Instruct — accept Meta license first
  • Qwen/Qwen2.5-7B-Instruct — ungated smoke test
  • TinyLlama/TinyLlama-1.1B-Chat-v1.0:featherless-ai — pin Featherless

Usage is metered (free tier + paid). Partial runs show coverage in the log if credits run out.

Custom — you run vLLM (e.g. on DCC) and point this app at it.

  1. Start vLLM with your repo id, e.g. MODEL="Qwen/Qwen3-0.6B" scripts/dcc/start_vllm.sh then scripts/dcc/wait_vllm.sh.
  2. Note the node and port (usually :8000); health check: curl http://<node>:8000/health.
  3. From a laptop: DCC compute nodes are internal — tunnel first:
    ssh -N -L 8000:<node>:8000 user@dcc-login
  4. Model field: HF repo id loaded in vLLM (e.g. Qwen/Qwen3-0.6B).
  5. Base URL: http://localhost:8000/v1 (tunneled) or http://<node>:8000/v1 (from login node / host-mode frontend).
  6. API key: local-vllm or leave blank.

Example: model WeiboAI/VibeThinker-3B, base URL http://localhost:8000/v1, key local-vllm

Works for any HF repo vLLM supports — no provider allowlist. Best for models not on HF hosted inference.
